Publishing the latest official APKs from https://commondatastorage.googleapis.com/chromium-browser-snapshots/index.html?prefix=Android_Arm64%2F
- Automates the process of checking, unzipping, and publishing releases of the latest .apk file

I made this fork specifically for myself to add this as an app in Obtainium, which currently has no way to grab the link from the official Chromium download site, as such a new build will be checked for every 5 minutes (GitHub Actions minimum run frequency) to ensure the latest release here is as up to date as possible
